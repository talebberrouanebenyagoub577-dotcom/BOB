# 08 — Content, Authority & Trust System

> Trust is not a section on the page — it is every element on every page.
> Saudi women buy at premium prices when they trust the brand completely.

---

## 1. The Trust Stack (Layered System)

Trust must be communicated at 5 levels simultaneously:

```
Level 1 — BRAND TRUST      → "This brand looks real and credible"
Level 2 — PRODUCT TRUST    → "This product is real, quality, and will work"
Level 3 — TRANSACTION TRUST → "My money and my data are safe"
Level 4 — DELIVERY TRUST   → "I will actually receive this"
Level 5 — RISK REMOVAL     → "If I don't like it, I can return it"
```

Each level is communicated through specific elements — detailed below.

## 6. Certification & Compliance (Real vs. Fake)

### What to State (Factual)
```
"مواصفات المنتج ووثائق الامتثال متاحة عند الطلب"
"المواد المستخدمة مطابقة لمعايير الاستخدام اليومي الآمن"
"اللاصق المستخدم من فئة 3M الصناعية المعتمدة للاستخدام الخارجي"
```

### What Never to Show
- ❌ Fake CE / FDA / SASO badges unless you have real documentation
- ❌ "معتمد من وزارة الصحة" for a car accessory
- ❌ "موافق عليه سعودياً" without actual documentation
- ❌ Any badge image from generic Shopify themes

### Authentic Trust Badges You CAN Use
- COD badge (custom designed, not a standard)
- "Delivery in 2-5 days" graphic
- "Free returns within 7 days" graphic
- "100% secure — no card required" graphic

These are promises you control and can deliver — they build real trust.

### Return Policy (Full — for policy page)
