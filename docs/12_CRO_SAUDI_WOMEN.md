## 2. Emotional Copywriting Framework

### The 5-Step Emotional Arc (Every product page must follow this)

```
① RECOGNITION   — "هذي أنا بالضبط"
    Show her exact problem. She must recognize herself immediately.
    No solution yet. Just mirror her reality.

② VALIDATION    — "نعم، هذه مشكلة حقيقية وليست مبالغة"
    Validate that her frustration is legitimate.
    Use a stat, a study, or a universal truth.

③ MECHANISM     — "إليك لماذا يحدث هذا وكيف يتم حله"
    Explain the science/logic of the problem.
    Then show the specific solution mechanism.
    She buys logic + emotion together.

④ PROOF         — "نساء مثلك جربن هذا وهذا ما قلنه"
    Reviews from Saudi women. Specific names, cities, outcomes.

⑤ ACTION        — "خطوة واحدة بسيطة — بدون مخاطرة"
    The lowest-friction CTA possible.
    Reinforce: "الدفع عند الاستلام — راجعيه قبل ما تدفعين"
```

## 3. Section-by-Section Emotional Architecture

### Hero Section

**Goal:** Hit recognition in < 3 seconds on mobile.

**Emotional target:** Recognition + curiosity

**Copy formula:**
```
Headline: [مشكلتها بالاسم] — without solution yet
Sub: [عدد المرات] + [المشاعر المرتبطة] + [التكرار اليومي]
CTA: "اكتشف الحل"  (not "اشتري الآن" — too early)
```

**Example:**
```
"سيارتك فوضى وأنت مرهقة قبل ما تبدأ يومك؟"
"ملايين السعوديات يبدأن يومهن بالبحث عن مفاتيحهن في نفس الفتحة — مرة أخرى."
```

**Visual Rule:** Show a real-looking car interior that feels familiar — not a showroom car. She must feel "هذي سيارتي تقريباً."

---

### Pain Strip (3 Pain Points)

**Goal:** Triple recognition. If she relates to even one, she's engaged.

**Format:** Icon + Problem + ONE sentence that stings

```
🔑  الأغراض تختفي يومياً
    كل يوم تضيع دقيقتان تبحثين في نفس الفتحة الملعونة.

😤  الفوضى تأكل ثقتك
    سيارة غير مرتبة تجعل كل رحلة تبدأ بتوتر.

😰  الاصطفاف يخوّفك
    كل موقف ضيق يأتي مع قلق الخدش — يومياً.
```

---

### "كيف يعمل" Section (Mechanism = Science Trust)

**Goal:** Build rational trust through mechanism clarity.

**Saudi women respond to "لأن" (because):**

```
DON'T: "منتج رائع يحل مشاكلك"
DO:    "يعمل لأن [آلية محددة] — مصممة خصيصاً لـ [المشكلة المحددة]"
```

**Example:**
```
"المنظّم يعمل لأن:
 الفوضى لا تحل بالإرادة — تحل بالبنية.
 كل جيب مصمم لحجم وشكل محدد لأغراضك اليومية.
 لا تفكيرين. كل شيء له مكان واحد."
```

---

### Materials/Specs Block (Ingredient Transparency)

**Goal:** Build premium trust through radical transparency.

Saudi women buying premium products expect to KNOW what they're buying.
Frame materials like a beauty brand frames ingredients:

```
🧪 ما يصنع هذا المنتج:

مادة أكسفورد 600D ← لأنها تتحمل الاستخدام اليومي والحرارة
خياطة مزدوجة ← لأنها لا تنقلع عند الضغط
أحزمة مرنة قابلة للتعديل ← لأن كل سيارة مختلفة
```

---

### Social Proof (Reviews)

**Goal:** She must see herself in the reviewer.

**Review Requirements:**
- Arabic name (real-sounding: نورة، سارة، ريم، لمى، منى، هند)
- Saudi city (الرياض، جدة، الدمام، الخبر، مكة)
- Specific outcome mentioned (not vague praise)
- Before/after implied in the text
- Rating: 5 stars (one 4-star for realism)

**Emotional Review Template:**
```
"[المشكلة التي كانت تعانيها] — [الحل الذي وجدته] — [كيف تشعر الآن]"

Example:
"كنت كل يوم أوصل شغلي وأبدأ بالبحث في نفس الفتحة.
الحين مكانها ثابت من أول يوم. أصغر شيء لكن أكبر فرق."
— لمى خ. — الرياض ★★★★★
```

### Trust Bar (Near Every CTA)

**Goal:** Eliminate financial fear completely.

**Must contain all 4 elements together:**

```
✓ الدفع عند الاستلام     — راجعيه قبل ما تدفعين
✓ بدون بطاقة أو تسجيل
✓ إرجاع مجاني 7 أيام
✓ توصيل 2-5 أيام
```

**Why COD is emotional:**
For Saudi women especially, COD is not just convenience — it is safety.
It says: "أنتِ في السيطرة. أنتِ تختارين."

---

### Scarcity (Ethical + Emotional)

**Goal:** Create urgency without manipulation.

**Use natural scarcity language:**
```
✅ "تبقّى 7 قطع هذا الأسبوع — الكمية تتجدد شهرياً"
✅ "هذه الدفعة وصلت هذا الأسبوع — الطلبات تسبق الكميات"
❌ "سينتهي العرض خلال 00:05:32" ← fake countdown = trust killer
```

## 4. Trust Signals by Type

### Science Trust (Logic)
Use these phrases to activate rational buying:

```
"يعمل لأن [آلية فيزيائية/مادية]"
"صُمم خصيصاً لـ [مشكلة محددة]"
"المادة [اسم المادة] تتحمل [درجة حرارة/ضغط] — لهذا اخترناها"
"اختبرناه في [ظروف محددة] — النتيجة [نتيجة قابلة للقياس]"
```

### Authority Trust (Credibility)
```
"اخترناه بعد دراسة أكثر مشاكل القيادة شيوعاً في السعودية"
"نوضح المواد لأنك تستحقين أن تعرفي ما تشترين"
"600+ عميلة راضية في المملكة"
```

### Social Trust (Belonging)
```
"نساء من الرياض وجدة والدمام اخترن هذا اليوم"
"من اشترت هذا المنتج اشترت [المنتج الثاني] أيضاً"
```

### Risk Trust (Safety)
```
"الدفع عند الاستلام — راجعيه قبل ما تدفعين"
"إرجاع مجاني 7 أيام — لا أسئلة ولا تعقيد"
"بياناتك آمنة — لا نطلب بطاقة ولا نخزن بيانات مالية"
```

## 5. CRO Micro-Copy Rules

### CTA Button Copy
Never generic. Always benefit-hinting + trust:

```
❌ "اشتري"
✅ "اشتري الآن — الدفع عند الاستلام"

❌ "تأكيد"
✅ "تأكيد طلبي — بدون دفع مسبق"

❌ "أضف للسلة"
✅ "أضف — وتدفعين عند الاستلام"
```

### Form Labels
```
❌ "الاسم"
✅ "اسمك الكامل — للتواصل بشأن الطلب"

❌ "رقم الجوال"
✅ "رقم جوالك السعودي — لتأكيد الطلب"
```

```
❌ "رقم خاطئ"

❌ "اسم غير صالح"
✅ "أدخلي اسمك الكامل (حرفان على الأقل)"
```

## 7. Video & UGC Content Strategy (TikTok/Snapchat)

### Hook Formulas for Saudi Women

**Pattern 1 — Problem Recognition Hook:**
```
"لو وقع جوالك مرة وأنتِ تقودين — هذا الفيديو لك"
"كل بنت عندها سيارة شافت هذا قبل — صح؟"
"٣ ثواني وتحلين أكبر مشكلة في سيارتك"
```

**Pattern 2 — Before/After Hook:**
```
"سيارتي قبل وبعد نظام أوتو — الفرق صادم"
"كنت أبحث عن مفاتيحي كل يوم — هكذا حليت المشكلة"
```

**Pattern 3 — Science/Curiosity Hook:**
```
"سبب فقدان الأغراض في سيارتك ليس الإهمال — بل التصميم"
"هذا ما لا تعرفينه عن سقوط الجوال أثناء القيادة"
```

### UGC Script Template
```
[0-2s] — Hook: مشكلة مرئية واضحة (ابحث عن المفاتيح، جوال يقع)
[2-8s] — Validation: "كنت أعاني من هذا كل يوم"
[8-20s] — Solution reveal + demo تركيب سريع
[20-30s] — Result: "الحين صار كل شيء في مكانه"
[30s] — CTA: "رابط في البيو — دفع عند الاستلام"
```
